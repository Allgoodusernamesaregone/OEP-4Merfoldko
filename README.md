# OEP-4Merfoldko

This repository contains an independent C# university project designed and developed from scratch based on **Object-Oriented Programming (OOP)** principles. The application models a simulation environment featuring dynamic interactions between cities, tourists, and state-driven behaviors.

## 📁 Repository Structure

*   **`/src`** – Contains the complete Visual Studio solution (`.sln`) and source code:
    *   **`4.merfoldko/`** – Core application logic, structured cleanly into domain modules (`Cities`, `CityStates`, `Tourists`, `Exceptions`, etc.).
    *   **`4.merfoldkoTest/`** – Unit tests validating the core simulation logic and domain rules.
*   **`/docs`** – System documentation and architectural plans:
    *   Contains the project specification/task description (PDF).
    *   Includes visual system architecture diagrams (`.drawio`).

## 🛠️ Key Technologies & Architectural Concepts

*   **Language & Environment:** C#, .NET, Visual Studio
*   **Design & Architecture:** Object-Oriented Programming (OOP), Clean Code principles, custom design patterns, and strict data encapsulation
*   **Quality Assurance:** Automated Unit Testing
*   **Documentation:** Visual architecture planning using `.drawio` (diagrams.net)

## 📌 Overview & Documentation

The complete logic of the simulation and formal assignment requirements are detailed in the documentation available in the `/docs` directory. Visual system designs and class hierarchies can be inspected using the `.drawio` architecture file.
